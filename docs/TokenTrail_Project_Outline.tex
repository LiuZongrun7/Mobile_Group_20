\sect{1. App idea and user problem}
Students and independent developers may use several coding agents, but their logs and provider views are separate. Token totals alone do not explain expenses. They need a shared view of recorded spending and an accessible way to ask what changed or whether a budget is at risk.

TokenTrail is an Android API-cost app for users of \textbf{Codex with OpenAI}, \textbf{ZCode with Xiaomi MiMo} and \textbf{DeepSeek Harness (DSH) with DeepSeek}. Its analytics home screen shows estimated costs, usage, sessions and budgets from available, authorised records of pay-as-you-go API calls. A \textbf{forum} provides model news and tips, and a \textbf{monthly tower-defence game} reflects already logged usage as progress; both are supporting extensions.

An \textbf{interactive home-screen AI assistant} provides an \textbf{``Ask AI / hold to talk''} entry above navigation. Tap to open an expandable question panel, or hold to dictate a question. The assistant explains cost changes, signals budget warnings and compares logged agent costs with evidence. It belongs to \textbf{TokenTrail's analytics experience}, works independently of the game, and \textbf{does not run, route or control} coding agents.

Scope is \textbf{pay-as-you-go API usage}, estimated from dated official-rate snapshots. \textbf{Token Plan and other subscriptions are excluded}, including their usage and quotas: subscription consumption cannot be treated as a per-call API charge. An API key alone cannot recover an agent's history. Missing logs/rates remain visible; amounts are estimates, and the assistant's own model usage and cost are recorded separately.

\sect{3. Proposed contribution}
\textbf{Unified analytics.} De-duplicate authorised logs and show source, coverage and session detail only where records support it. \textbf{Reproducible costs.} Java applies dated official rates by provider, model, token class and service tier, preserving the price version. \textbf{Evidence-based AI advice.} Text or speech questions obtain calculated evidence from read-only tools; replies disclose sample size and missing data. Compare recorded costs, tokens and cache use, not answer quality; no task ratings are required. Values remain \emph{Estimated}, \emph{Partial estimate} or \emph{Unavailable}.

\tagline{\textbf{Scope rule:} API-cost analytics and the home-screen assistant are core; forum and game are supporting extensions. Live cross-agent status and system-wide overlays are outside the first release.}

\sect{5. Core features and implementation approach}
The analytics dashboard and assistant form the main experience; Forum and Game are supporting tabs.
\begin{itemize}
  \item \smallhead{Account and profiles.} Register, log in/out and reset passwords. Record the coding tool, provider, billing mode and a non-secret key label; coding-agent credentials are not required.
  \item \smallhead{Usage, costs and sessions.} Import and de-duplicate authorised records. Only confirmed pay-as-you-go coding-agent records enter totals, budgets and game resources; exclude Token Plan, subscriptions and unknown billing modes. Match timestamps, provider/model, token classes and pricing tiers to official snapshots, including cache and time-based rates where applicable. Session attribution requires identifying logs; aggregates never become invented sessions. Source-billed amounts are separate reconciliation evidence, not replacements for estimates.
  \item \smallhead{Budget and price updates.} Show estimated spend, coverage, budget progress and advisory alerts; forecast only from comparable history. Preserve source URL, currency, effective time and price version; CNY conversion retains its exchange-rate snapshot. Missing historical rates or insufficient timing detail mean unavailable cost, not zero or a backdated current price. No payments or external hard caps.
  \item \smallhead{Interactive AI assistant and separate API cost tracking.} A floating \textbf{``Ask AI / hold to talk''} entry opens the home-screen panel. Type, or dictate and review/edit the transcript before sending. Request microphone permission on use; denial or failure leaves typing available. Raw audio is not retained by default. A Java service calls one selected OpenAI, Xiaomi MiMo or DeepSeek pay-as-you-go model and reads validated summaries. Replies explain spending/cache changes and compare costs only when comparable logs support them, citing coverage, price versions and missing data. Community tips are supplementary, never pricing authority. Rule-based alerts need no model call; assistant tokens/costs have a separate ledger, excluded from coding-agent totals and game resources.
  \item \smallhead{Supporting forum.} Show linked official news, user posts and replies. Rank by recency/helpful votes with deterministic ties. Label community tips and keep public content separate from private usage.
  \item \smallhead{Supporting tower-defence game.} A separate Game tab offers monthly progression from already logged pay-as-you-go coding-agent tokens. Input, cache and output map to resource pools for towers and walls. Players place/upgrade defences, protect a core and start real-time waves; health, wave progress and battle results provide feedback. Save monthly game state separately; playing never changes usage, cost or budget totals. No extra API spending is needed, and re-importing logs grants no duplicate resources.
\end{itemize}
